# Política de Privacidade — Aurora Commerce

**Versão:** 1.0  
**Última Atualização:** 03/08/2026  
**Responsável:** Jurídico & Compliance

## 1. Coleta de Dados Pessoais
A Aurora Commerce coleta informações essenciais para a realização de compras, tais como: nome completo, CPF, endereço de entrega, e-mail e telefone de contato. Dados transacionais e de navegação também podem ser armazenados para fins operacionais e de melhoria contínua.

## 2. Uso das Informações
Os dados coletados são utilizados exclusivamente para:
* Processar e enviar pedidos;
* Emitir notas ficais;
* Comunicar atualizações sobre o status do pedido;
* Prestar suporte ao cliente e gerenciar trocas ou devoluções.

## 3. Compartilhamento de Dados
Não comercializamos dados pessoais. O compartilhamento ocorre apenas com parceiros estritamente necessários para a operação, como a transportadora **RotaLog** para realização de entregas e gateways de pagamento para processamento financeiro.

## 4. Direitos do Titular (LGPD)
Conforme a Lei Geral de Proteção de Dados (LGPD), o cliente possui o direito de solicitar a confirmação, acesso, correção ou eliminação de seus dados pessoais a qualquer momento através do nosso canal de atendimento: `privacidade@auroracommerce.com.br`.
